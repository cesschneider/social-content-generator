## Week 1 — The Mindset Shift (Days 1–7)

Core argument: The SDLC has fundamentally changed, not in tooling, but in the cognitive model of software engineering. Vibe coding is not a shortcut — it is a new discipline with its own rigor.

Key topics: defining "vibe coding" vs. ad-hoc prompting, the three levels (ad-hoc → structured → agentic), why context is the new code, the spec-first workflow.

---

## Week 2 — The New Toolkit (Days 8–14)

Core argument: The engineering environment has a new layer. Mastering it requires learning prompt patterns, context management, and knowing which AI capabilities to trust and which to verify.

Key topics: local AI setup, prompt patterns (CoT, few-shot, role-based), RAG vs. fine-tuning, personal prompt libraries, AI-assisted code review, context window management.

---

## Week 3 — Agentic Engineering (Days 15–21)

Core argument: The step change is not in better prompting — it is in building systems where AI agents take sequences of actions autonomously. This requires new safety primitives and new design patterns.

Key topics: multi-agent architectures, orchestrator/subagent mental model, test generation pipelines, autonomous debugging, CI/CD integration, agent safety, human-in-the-loop design.

---

## Week 4 — Org-Level Transformation (Days 22–30)

Core argument: Individual productivity gains from AI are table stakes. The organizations that win will be the ones that restructure their engineering culture, documentation, and measurement systems around AI-native workflows.

Key topics: team adoption patterns, AI-friendly documentation, productivity metrics, CLAUDE.md pattern, security in agentic systems, the transition from vibe coder to agentic engineer, the new engineering org, and the durable principles that will survive the next tool cycle.
